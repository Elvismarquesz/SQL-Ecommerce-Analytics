# 📊 SQL E-commerce Analytics

Projeto desenvolvido para demonstrar habilidades em **SQL**, modelagem de banco de dados e análise de dados utilizando a base pública da Olist.

---

# 🎯 Objetivo

Construir um banco de dados relacional completo, importar dados reais de um e-commerce brasileiro e responder perguntas de negócio utilizando SQL.

---
